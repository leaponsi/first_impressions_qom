# Data folder

This folder contains the main datasets used in the project.

## Contents

- `all_participants_raw_movements.csv`: raw movement signal data
- `all_participants_preprocessed_movements.csv`: preprocessed movement data
- `all_participants_movement_features.csv`: extracted movement features used in the analyses
- `data_1st_imp.xlsx`: original first impression dataset in Excel format
- `data_imp.csv`: cleaned first impression dataset

## Group folders

- `P/`: patient-related data
- `SZ/`: schizophrenia-related data
